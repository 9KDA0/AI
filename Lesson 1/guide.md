
## 🔧 Если что-то пошло не так

| Проблема | Проверка / Решение |
|----------|-------------------|
| Программа не установилась | `for cmd in git gh node npm python3 zed; do command -v $cmd &> /dev/null && echo "✅ $cmd" \|\| echo "❌ $cmd"; done` |
| CodeWhale не ставится через npm | `brew install node` (переустановка Node.js) |
| Не пушится на GitHub | Попроси CodeWhale: «Проверь git config, gh auth status, remote URL» |
| Не понимаешь, что делает ИИ | Скажи: «Объясни простыми словами, как будто мне 12 лет» |
| DeepSeek API не работает | Проверь баланс, правильность ключа, `codewhale doctor`, [status.deepseek.com](https://status.deepseek.com) |
| `gh` не авторизуется | `gh auth logout && gh auth login` |
